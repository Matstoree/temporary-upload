Halaman ini merupakan antarmuka sederhana untuk API HTTP di bawah ini. Anda dapat memanggil API secara langsung untuk mengotomatiskan proses unggah file.

POST /api/upload

Mengunggah sebuah file dan mengembalikan tautan unduhan. Kirim permintaan sebagai multipart/form-data. Endpoint ini dibatasi hingga 4MB per file (batas ukuran permintaan di Vercel); untuk file yang lebih besar gunakan formulir di halaman ini, yang mengunggah langsung ke storage.

  • filefile itu sendiri, tipe apa saja
  • expiry 5m15m30m1h1d3d1wpermanent 
curl -X POST BASE_URL/api/upload \
  -F "file=@/path/file.jpg" \
  -F "expiry=1h"

Mengembalikan JSON berisi id, filename, size, expiry, dan url. Ekstensi file asli otomatis ditambahkan di akhir url (mis. /f/3YL2vUDn.jpg) supaya klien lain mudah menebak tipe filenya.

GET /f/:id

Mengunduh atau menampilkan pratinjau file. Gambar, video, audio, dan PDF akan terbuka langsung di browser; tipe file lainnya langsung terunduh. Mengembalikan status 404 jika file sudah kedaluwarsa — file yang kedaluwarsa akan dihapus secara otomatis dan tidak tersedia endpoint untuk menghapus file secara manual.

curl -O -J BASE_URL/f/FILE_ID

Ganti BASE_URL dengan alamat situs ini. Masa berlaku ditentukan saat file diunggah dan tidak dapat diperpanjang setelahnya.
